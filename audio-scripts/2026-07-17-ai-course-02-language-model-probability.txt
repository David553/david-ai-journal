第2课：语言模型到底在算什么 —— 概率建模、logits 与 softmax

本课目标

第1课我们讲了自回归生成的"流程"：模型一个 token 一个 token 往外吐，靠注意力机制回看前文，用 KV Cache 省计算。但有一个核心问题被跳过了：每一步，模型吐出来的到底是什么？ 答案是——一个概率分布。

本课对应课程路线 A.1 中尚未覆盖的部分：概率建模。它是整个知识图谱的地基：后面讲损失函数（第5课方向）你需要知道"模型输出的是概率"；讲解码策略（temperature、top-p）你需要知道"采样是从分布里抽签"；讲量化和推理优化你需要知道"logits 这一层长什么样"。学完本课，你能回答：*"为什么同一个 prompt，模型每次回答不一样？"* 以及 *"perplexity 这个指标到底在量什么？"*

2. 词表与 logits：模型的原始输出

模型不认识"所有可能的词"，它有一个固定的词表（vocabulary），比如 5 万或 15 万个 token（token 概念第1课已学）。预测下一个 token 时，模型对词表里每一个 token 都输出一个实数打分，这些原始分数叫 logits。

至此，Transformer 的一次前向计算可以完整描述为：前文 tokens → 网络内部计算（含第1课的注意力）→ 词表上的 logits → softmax → 概率分布。

4. 采样 vs 贪心：随机性从哪来

拿到分布后有两种基本取词方式：

- 贪心（greedy）：永远选概率最高的。确定性，但容易复读、僵硬。
- 采样（sampling）：按概率抽签——85% 概率抽到"垫子"，13% 抽到"树"。

这就回答了开头的问题：同一个 prompt 每次回答不同，不是模型"心情"变了，而是每一步都在按分布掷骰子，且早期一个 token 的不同会通过自回归级联放大。

5. perplexity：衡量模型"惊讶程度"

怎么评价一个语言模型好不好？看它给真实文本分配的概率高不高。困惑度（perplexity）是标准指标，直觉定义：*模型在每一步平均"犹豫"于几个候选之间*。

- 完美模型每步都确信正确答案 → perplexity = 1；
- 完全瞎猜（5 万词表均匀分布）→ perplexity = 50000；
- GPT-2 在标准测试集上约 20-35，意思是"平均每步像在二三十个词里选"。

数学上它是平均负对数概率的指数：PPL = exp(-1/N × Σ log P(真实的下一个token))。真实 token 被给的概率越高，PPL 越低。这个"负对数概率"就是后面训练课里交叉熵损失的雏形——训练的全部目标，就是把真实文本的 PPL 压低。

回到案例：GPT-2 为什么震撼

GPT-2 的方法部分用本课语言一句话就能说完：在 40GB 网页文本上训练一个 Transformer，目标只有一个——最小化下一个 token 的负对数概率（即压低 perplexity）。

震撼在于结果：没有教它任何任务，但因为互联网文本里天然包含"英文段落后面跟着法语翻译"、"文章末尾跟着 TL;DR 摘要"这类模式，一个足够好的条件概率模型 P(下文 | 前文) 会顺便学会这些任务——给它 "英文句子 + 'French:'"，概率最高的续写自然就是法语翻译。这就是后来 prompt engineering 的理论根基：你不是在"命令"模型，而是在构造一个前文，使得你想要的输出成为条件概率最大的续写。
