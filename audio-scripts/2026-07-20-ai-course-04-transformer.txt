第4课：Transformer 全景 —— 残差流、MLP 与归一化如何拼成一个模型

本课目标

前三课你已经拿到了三块拼图：注意力机制（Q/K/V，第1课）、概率输出（logits → softmax，第2课）、embedding（第3课）。但它们是怎么组装成一个完整的 GPT 的？中间还缺三个你没学过的关键零件：残差连接（residual connection）、MLP 层、归一化（LayerNorm/RMSNorm）。学完本课，你能画出 Transformer 的完整数据流图，并且能看懂机制可解释性（mechanistic interpretability）论文里"某个头把信息写入残差流"这种说法到底在说什么——这在课程路线里对应 A.3，是后面训练、并行、推理优化所有内容的地基。

3. 残差连接：模型内部的"公共黑板"

注意上面伪代码的形式是 x = x + 子层(x)，而不是 x = 子层(x)。这个 + 就是残差连接，它带来一个极其重要的视角转换——残差流（residual stream）：

把每个 token 位置想象成一块贴身携带的黑板（一个 d 维向量），从 embedding 层出发，一路穿过所有 block 直达输出层。每个子层不是"替换"黑板内容，而是读一眼黑板，然后往上面追加写一点东西（加一个向量）。原有信息默认原样保留。

为什么要这样设计？两个原因：

- 训练可行性：几十层网络如果层层替换，梯度（第5课会讲）在回传时会逐层衰减/爆炸；有了 +，梯度可以沿着这条"高速公路"无损直达底层。这是深层网络能训起来的前提。
- 可解释性：因为大家共用一块黑板，我们可以问"第 3 层的某个注意力头往黑板上写了什么？第 7 层的谁把它读走了？"——层与层之间通过黑板通信，形成可追踪的回路（circuit）。今天的论文就是这么干的。

5. 用这套语言描述一个真实回路：induction head

模型是怎么学会"复读"的？比如上下文出现过 A B ... A，模型预测下一个是 B。可解释性研究发现这靠两个头接力：

- 浅层的 previous-token head：在 token B 的黑板上写下"我的前一个词是 A"；
- 深层的 induction head：当前 token 是 A 时，它的 Query 去和各位置黑板上"我的前一个词是___"的记号做匹配（Q/K 点积，第1课），找到 B 那个位置，把 B 搬过来作为预测。

两个头分工明确、通过残差流传递中间结果——这是"模型内部存在算法"的最经典证据，也是 in-context learning 的机制来源之一。

回到论文

有了以上概念，这篇论文就好读了。Diffusion 语言模型（DLM）不是自回归地从左到右生成，而是把一堆位置盖上 [MASK]，迭代地"去噪"填词（第9课会展开 diffusion，这里只需知道它每个位置能同时看左右两边）。论文问：DLM 也会 in-context learning，它内部也是 induction 回路吗？

作者训练了架构对齐的自回归模型和 DLM，然后做机制分析，发现 DLM 学到的是双向感应回路：不仅有 previous-token head（往残差流里写"我左边是谁"），还有 next-token head（写"我右边是谁"）——因为 DLM 能看到两侧，被 mask 的位置既可以从"左边匹配"也可以从"右边匹配"找到答案，induction head 随后从残差流里读出这些局部上下文记号、定位到匹配处并把答案 token 拷贝过来。整套分析的每一步——头的分工、写入/读取残差流、Q/K 匹配定位、拷贝——全是你本课学到的词汇。这也展示了可解释性研究的标准范式：把黑箱模型拆成"若干个头 + 一块黑板"的可读回路。
