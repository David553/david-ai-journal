第22课：从"对齐偏好"到"学会思考" —— 可验证奖励强化学习（RLVR）、GRPO 与测试时计算

本课目标

第9课我们走完了 SFT → 偏好学习（RLHF/DPO）这条线，但路线图 A8 还剩最后一块没讲：推理模型（reasoning model）是怎么训出来的。这是从"让模型愿意好好答"到"让模型愿意先想再答"的跨越，也是 o1/R1 这一代模型的核心训练范式。学完你能解释三件事：为什么数学和代码任务可以不要奖励模型；GRPO 相比 PPO 到底省掉了什么；以及为什么"RL 让模型变强了"这个说法在实验上极难证明。

今日论文

Phantom Gains（arXiv 2608.20290）：作者对 Qwen3-8B 做了三轮 LoRA 自训练，同时让一个完全没训练的冻结模型走一遍同样的评测流水线作对照，结果发现七种常见测量方式在没有对照组时都会凭空"造出"能力提升。

2. 策略梯度：不可微的目标怎么优化

第6课的训练是"算 loss → 求梯度 → 反传"。但这里的 loss 是"答案对不对"，是个离散判定，对参数不可微。怎么办？

换个思路：我们要最大化的是期望回报 $J(\theta)=\mathbb{E}_{y\sim\pi_\theta}[r(y)]$。有一个经典恒等式（REINFORCE）：

$$\nabla_\theta J = \mathbb{E}_{y\sim\pi_\theta}\big[\,r(y)\,\nabla_\theta \log \pi_\theta(y)\,\big]$$

它的直觉极其朴素：采样若干个回答，把答对的那些回答的 token 概率往上抬，答错的往下压。$\nabla\log\pi$ 就是普通的交叉熵梯度，我们只是给它乘了一个标量权重。所以 RL 训练在工程上并不神秘——它是"SFT 训练自己生成的数据，但每条数据带一个权重"。

3. baseline 与 advantage：为什么必须减去平均值

直接用 $r$ 当权重方差极大。假设一道简单题模型 8 次全对，$r$ 全是 1，梯度会无脑抬高所有 8 条回答——但其实没有任何"哪条更好"的信息。解法是减掉一个 baseline：

$$A(y) = r(y) - b$$

$A$ 叫优势函数（advantage）：比平均水平好多少。PPO 的做法是再训一个 critic（价值网络）来预测 $b$——但这意味着显存里要同时住着策略模型、参考模型、奖励模型、critic 四个模型（回忆第16课的显存账）。

6. 测试时计算：训练的成果花在推理上

RLVR 训出来的模型，行为变化是输出变长了——先写几千 token 的思考再给答案。这叫 test-time compute（测试时计算）：不增加参数，而是增加推理时的 token 预算来换准确率。同族的还有两个不需训练的做法：self-consistency（采 N 个答案取多数投票）和 best-of-N + verifier（采 N 个用验证器挑）。

7. 关键争议：sharpening 还是 acquisition

用第21课的 pass@k 一测，就会看到一个尴尬现象：RLVR 后 pass@1 明显上升，但 pass@256 常常不变甚至下降。解释是：RL 并没有教会模型新知识，只是把概率质量集中到基座模型本来就偶尔能采到的正确路径上——这叫 sharpening（锐化），而非 acquisition（获得新能力）。分布变尖了，pass@1 涨；多样性丢了，大 k 的覆盖率反而降。

回到论文

Phantom Gains 攻击的正是"如何证明 acquisition"这件事。它不看平均准确率，而看逐题的得失账本（ledger）——哪些题从错变对、哪些从对变错。这需要对两次含噪估计做差，于是极易被测量噪声污染。作者的关键设计是一个 measured null：让一个没被训练的冻结模型走完全相同的流水线，看它"应该为零"的增益到底是多少。

结论很有杀伤力：
- 用单次 greedy 解码建账本时，未训练模型也表现出大量"能力变化"。原因大部分是推理时的 batching 非确定性——batch 尺寸变化会改变 GPU kernel 的归约顺序，浮点加法不满足结合律（第14课），logits 出现微小扰动，恰好把接近平局的 argmax 翻了面。
- 用来区分 acquisition 与 sharpening 的 expansion 统计量，给这个根本没训练的模型打出了 0.280 的"获取率"。
- 七种失效模式，每一种在缺少对照组时都会反转已报告的结论。

翻译成方法论：在报告 per-problem 级别的自我提升之前，必须先测出你的流水线在零信号下的噪声底。这条纪律和第21课的评测可复现性是同一件事的两面。
