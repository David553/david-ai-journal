第11课：让语言模型"看见" —— ViT、模态对齐与视觉语言模型（VLM）

本课目标：按课程路线，A 部分只剩两块拼图，今天讲第 10 项「多模态模型」。它站在你已有知识的交汇点上：Transformer 结构（第4课）、embedding 与 CLIP（第3课）、SFT（第9课）、KV Cache（第1课）全都会被复用。学完你能回答：一张图片在 Qwen2-VL、GPT-4V 这类模型内部到底变成了什么？为什么说"图像也是一种 token"？为什么多模态推理比纯文本更贵？

今日论文：选 [8]《Bigger or Cheaper?》——它用 Qwen2-VL 系列研究一个非常工程师的问题：固定显存预算下，部署"小模型全精度"、"小模型 4-bit 量化"还是"大模型 4-bit 量化"，当输入图像被模糊、噪声退化时，模型的置信度信号哪种配置还靠得住。

背景铺垫

1. 图像的"tokenizer"：ViT 与切块（patchify）

文本进模型前要过 tokenizer 变成 token 序列（第2课）。图像没有天然的"词"，Vision Transformer（ViT）的做法简单粗暴：把图切成小方块。一张 224×224 的图，按 16×16 切，得到 14×14 = 196 个 patch。每个 patch 展平成一个长向量（16×16×3 = 768 个数），过一个线性层投影到模型维度 d，再加上位置编码（第5课，让模型知道哪块在左上、哪块在右下）：

2. 眼睛从哪来：视觉编码器

VLM 不会从零训练视觉部分。第3课讲过 CLIP 用对比学习把图和文拉进共享嵌入空间——它的图像塔（一个 ViT）输出的向量已经高度"语义化"。主流 VLM 直接拿预训练好的 CLIP-ViT（或改进版 SigLIP）当眼睛。

3. 模态对齐：projector 是"翻译官"

问题来了：视觉编码器输出的向量空间和 LLM 的词嵌入空间是两个互不相通的坐标系——眼睛说的是方言，LLM 听的是普通话。projector（连接器）负责翻译，它往往简单得惊人：一两层 MLP，把每个 patch 向量映射到 LLM 的 embedding 空间。翻译后的向量被称为图像 token，直接拼在文字 token 前面塞进上下文：

后续文字 token 通过普通的注意力机制"看"这些图像 token，不需要任何特殊结构。这就是 LLaVA 的经典公式：VLM = 预训练视觉编码器 + projector + 预训练 LLM。

代价也清楚了：一张高分辨率图可能产生几百上千个图像 token，它们占上下文窗口，prefill 时也全部进 KV Cache（第1课）——这就是多模态推理更贵的根源。

4. 置信度与校准

模型答题时怎么知道它"有多大把握"？两种信号：(a) 口头置信度——直接让它用自然语言说"我有 80% 把握"；(b) 平均 token 概率——把它生成答案时每个 token 的 softmax 概率（第2课）取平均。校准（calibration）衡量置信度是否追踪正确率：说 90% 就应该对 90%。校准好，系统才能做选择性回答（defer）：把握低就拒答或转人工——端侧部署的安全阀。注意这两种信号可能打架：RLHF（第9课）的偏好数据往往奖励"自信的语气"，会让口头置信度虚高，但它并不直接优化概率的校准。

回到论文

现在 [8] 的设计一句话就能说清：固定显存预算下比较三种配置——小模型 FP16、小模型 4-bit、大模型 4-bit（量化概念见第1课）——在相同输入上测量两种置信度信号。再叠加一个变量：对输入图像做退化（模糊、噪声），让分布偏移从"眼睛"这一侧进入。你能看懂它每个实验轴的含义：模型规模是第7课的 scaling 变量；量化扰动的是整条流水线（视觉编码器 + projector + LLM）的权重精度；图像退化扰动的是输入；两种置信度信号对应上面第 4 点。论文在 5700 条预测上对照测量，本质是在替消费级硬件上的部署者回答："bigger" 和 "cheaper" 谁买到的置信度更值——这决定了你的 VLM 该在什么时候闭嘴。
