第28课：条件是怎么"进"去的 —— Classifier-Free Guidance、Latent Diffusion 与少步采样

本课目标

第10课讲的是无条件 diffusion：从纯噪声里雕出"某张图"。但你实际用到的每一个扩散系统——Stable Diffusion、超分、视频生成、今天这批论文里的降水降尺度和医学分割——都是条件模型：给一段文字、一张低清图、一个粗网格气象场，生成对应的输出。从 DDPM 那篇论文到"能用的产品"之间，隔着三件事：条件怎么注入网络、怎么让模型真的听话（guidance）、怎么把 1000 步 × 全分辨率的账压到能跑（latent + 少步采样）。这一课把这三件事补上。

学完你能解释：为什么 CFG scale 调到 15 图更"听话"但颜色过饱和、细节崩坏；为什么 SD 出图 512×512 但 UNet 其实只在 64×64 上算；为什么一次条件生成实际要跑两次前向；以及为什么超分任务里 latent diffusion 天生有个保真度天花板。

今日论文

Precipitation Downscaling Using Foundation Model-Conditioned Diffusion（2026-08-26）——把气象降尺度（粗网格 → 高分辨率日降水，本质是"物理版超分"）当成一次条件注入方式的消融实验，正面比较通道拼接 / 交叉注意力 / 冻结气象基础模型编码器三条路线。

背景铺垫

0. 一句话锚点

复习第10课的桥：加噪 $x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\varepsilon$，网络 $\varepsilon_\theta(x_t,t)$ 预测噪声，而它等价于 score：$\nabla_x \log p(x_t) = -\varepsilon_\theta / \sqrt{1-\bar\alpha_t}$。"预测噪声"和"估计对数概率的梯度"是同一件事——下面所有推导都踩在这条桥上。

1. 条件怎么进网络：三条路

现在网络变成 $\varepsilon_\theta(x_t, t, c)$。$c$ 长什么样，决定了它怎么进去：

(a) 通道拼接（concat）。当 $c$ 和 $x_t$ 像素对齐、同分辨率时——低清图、分割掩码、上采样后的粗网格气象场——直接沿 channel 维拼上去，torch.cat([x_t, c], dim=1)，第一层卷积的输入通道数改一下就完事。零额外参数，空间对应关系是硬编码的：输出第 $(i,j)$ 个像素天然看得见条件第 $(i,j)$ 个像素。

(b) 归一化调制（FiLM / adaLN）。当 $c$ 是一个全局向量（类别标签、时间步 $t$ 本身、一个 CLIP 图像向量），把它过一个小 MLP 预测出 scale 和 shift，去调制归一化层：h = norm(h) * (1 + γ(c)) + β(c)。这就是 $t$ 一直以来的注入方式，DiT 里的 adaLN 也是它。

(c) 交叉注意力（cross-attention）。当 $c$ 是变长序列、且不与图像空间对齐（一句 prompt 的 token 序列、一个编码器的输出序列），用第4课的注意力：Q 来自图像特征（把 UNet 某层的空间特征 flatten 成 $HW$ 个 token），K/V 来自条件序列。

三者的区别不是"哪个更强"，而是假设不同：concat 假定"条件和输出逐像素对应"，cross-attn 假定"我自己去条件里检索需要的部分"。选错了，模型要么被迫学一个它本来免费拥有的对齐关系，要么被强加一个根本不成立的对齐。

2. Classifier-Free Guidance：让模型真的听话

直接训 $p(x|c)$ 有个老问题：条件信号太弱，模型倾向于生成"高概率的普通样本"，prompt 里的细节被忽略。

先看分类器引导的推导。贝叶斯：$\log p(x|c) = \log p(x) + \log p(c|x) - \log p(c)$，对 $x$ 求梯度（最后一项与 $x$ 无关，消失）：

$$\nabla_x \log p(x|c) = \underbrace{\nabla_x \log p(x)}_{\text{无条件 score}} + \underbrace{\nabla_x \log p(c|x)}_{\text{一个分类器的梯度}}$$

给第二项乘一个放大系数 $w$，等价于对 $p(x)\,p(c|x)^{w}$ 采样——把"符合条件"这件事锐化了。但这要额外训一个能吃带噪图像的分类器，很麻烦。

CFG 的技巧：把上式反解，$\nabla_x \log p(c|x) = \nabla_x\log p(x|c) - \nabla_x\log p(x)$，两项都是扩散模型自己能给的。换回 $\varepsilon$：

$$\tilde\varepsilon = \varepsilon_\theta(x_t,t,\varnothing) + w\cdot\big(\varepsilon_\theta(x_t,t,c) - \varepsilon_\theta(x_t,t,\varnothing)\big)$$

训练时以约 10% 概率把 $c$ 替换成空条件 $\varnothing$（一个可学习的占位 embedding），同一个网络就同时学会了有条件和无条件两种预测。不用分类器，所以叫 classifier-free。

三个必须记住的后果：

- 算力翻倍：每一步采样要跑两次前向（$c$ 和 $\varnothing$）。工程上把两者拼成 batch 一次算，但 FLOPs 是实打实的 2×（第13课的账）。
- $w$ 的含义：$w=1$ 就是普通条件生成，SD 默认 7.5。它本质是连续空间里的低温采样——和第8课的 temperature、第22课的 sharpening 是同一族操作。
- $w$ 过大会崩：CFG 是在"条件方向"上做线性外推，$w$ 大到一定程度就外推出了数据流形之外，表现为过饱和、高对比、结构畸变、多样性塌缩。下面的练习会让你在一维上亲眼看到这个外推。

3. Latent Diffusion：别在像素上算

$512\times512\times3 = 786{,}432$ 维。在这上面跑 50 步 UNet、再 ×2（CFG），训练和推理都贵得离谱。

关键观察是感知压缩 vs 语义压缩：一张图的绝大多数比特花在人眼和语义都不敏感的高频细节上。所以分两阶段：先单独训一个自编码器（VAE + 感知损失 + 对抗损失），把 $512\times512\times3$ 压到 $64\times64\times4$（压缩因子 $f=8$），元素数 786k → 16k，约 48 倍；然后把 diffusion 整个搬到这个 latent 空间上训练和采样，最后 decoder 一次性解回像素。这就是 Stable Diffusion——VAE 冻结、两阶段训练，结构上和第11课 LLaVA 的"冻结视觉编码器 + 训练连接层"是同一种分工思路。

代价要记住：VAE 是有损的。文字、小人脸、精细纹理的还原上限由 decoder 决定，diffusion 再强也突破不了。这正是超分任务里 latent diffusion 常常"看着真实但不忠实"的结构性原因。

4. 少步采样：DDIM

DDPM 的 1000 步来自它的马尔可夫链假设。DDIM 把反向过程改写成非马尔可夫的确定性映射：每一步先用 $\varepsilon_\theta$ 反推出干净图的估计 $\hat x_0 = (x_t - \sqrt{1-\bar\alpha_t}\,\varepsilon_\theta)/\sqrt{\bar\alpha_t}$，再把 $\hat x_0$ 重新加噪到任意更小的 $t'$。既然可以跳到任意 $t'$，1000 步就能抽稀成 20–50 步，且不用重新训练——同一套权重。副产品：$x_T \to x_0$ 变成确定映射，于是 latent 可反演、可插值，图像编辑类应用都建在这上面。

回到论文

降水降尺度：输入是粗网格的大尺度大气预报场（气压、风、湿度等多个物理通道），输出是高分辨率日降水。这就是一个标准的条件扩散问题，而这篇论文做的正是第1节那三条路的正面消融：

- arm 1 — 通道拼接：把粗场上采样到目标网格，沿 channel 拼进 UNet。假设"物理场与降水逐格点对应"。
- arm 2 — 交叉注意力 + 自训练卷积编码器：条件先过一个从头训的编码器变成序列，再用 cross-attn 注入。放松了逐格点对齐——降水可以"去别处查"水汽输送，代价是编码器要从这个任务的有限数据里自己学出大气表征。
- arm 3 — 交叉注意力 + 冻结的 Prithvi WxC 气象基础模型编码器：把预训练大气表征直接搬来当条件编码器。这是 SD "用冻结 CLIP 文本编码器"在气象领域的对应物，也呼应第27课"冻结底座 + 轻量适配"的整体思路——好处是白拿预训练表征，风险是这个表征不是为"当扩散条件"而优化的。

摘要在评测结论处被截断了，所以我不知道谁赢。但值得你带走的是问题本身：条件注入方式不是实现细节，它编码了你对"条件与输出之间是什么关系"的先验假设，而这个假设选错的代价，比换个 UNet 大小大得多。
