第34课：非线性是从哪来的 —— 激活函数、MLP 与 SwiGLU

本课目标

第4课我们把 Transformer block 拆成了「注意力 + MLP + 残差 + 归一化」，但当时对 MLP 只说了一句"逐 token 的两层前馈网络"，跳过了一个更根本的问题：那个夹在两层线性之间的非线性函数，到底在干什么？为什么没它整个模型就废了？

这是深度学习最底层的一块地基，前面 33 课一直踩在上面却没挖开过。补完它，你能回答这几个具体问题：

- 为什么"堆很多层线性变换"这件事在数学上根本没有意义？
- 为什么现代 LLM 的 FFN 是三个权重矩阵而不是两个？
- 为什么 Llama-7B 的 intermediate_size 是 11008 这么一个怪数字，而不是 4×4096=16384？
- 为什么 Transformer 里参数量最大的不是注意力，而是这个看起来最平凡的 MLP？

今日案例

今天没有合适的新论文，用一篇 2020 年的经典短文当案例：Noam Shazeer 的 《GLU Variants Improve Transformer》——全文不到 5 页，做的事是把 Transformer 的 FFN 换成门控形式（SwiGLU / GEGLU），结果被 PaLM、Llama、Qwen 全线抄走，成了今天几乎所有开源大模型的默认配置。

背景铺垫

1. 线性层堆叠会"塌缩"

一个线性层就是 $y = Wx + b$。把两层叠起来：

$$y = W_2(W_1x + b_1) + b_2 = (W_2W_1)x + (W_2b_1 + b_2) = W'x + b'$$

两层线性 = 一层线性。 一百层也一样，$W_{100}\cdots W_1$ 乘出来还是一个矩阵。深度在这里完全是浪费——你花了 100 倍的算力，得到的函数族和单层一模一样：只能做旋转、缩放、投影这类"把直线映射成直线"的变换。第3课讲 embedding 空间的语义算术时，那种线性结构很有用；但语言的绝大部分结构不是线性的。

所以每两层线性之间必须插一个非线性函数 $\sigma$，这就是激活函数：

$$\text{MLP}(x) = W_2\,\sigma(W_1x + b_1) + b_2$$

2. 非线性 = 给空间"折一下"

最好的直觉是 ReLU：$\text{ReLU}(z) = \max(0, z)$。它把所有负数压成 0，正数原样通过。几何上，这相当于沿着一条超平面把整个空间对折。

一次折叠把空间切成 2 个区域，每个区域内部仍是线性的；再叠一层，每个区域又被切开……$L$ 层之后，输入空间被切成指数级多的小块，每块上是一个不同的线性函数。整体就是一个分段线性函数——而任意连续曲线都可以用足够多的小线段逼近。

这就是万能逼近定理的直觉版本：单隐藏层 + 足够宽 = 能以任意精度逼近任意连续函数。但注意两个陷阱：

- 能表示 ≠ 能学到。定理只保证存在这样的权重，不保证 SGD 找得到（第6课）。
- 能表示 ≠ 划算。同样的分段数量，浅而宽的网络需要指数级多的神经元，深而窄的网络只要线性多层。这是"深度学习"而不是"宽度学习"的根本原因。

3. 激活函数家族：从饱和到平滑

sigmoid / tanh（老一代）：$\sigma(z)=1/(1+e^{-z})$。问题在导数：$\sigma'(z)=\sigma(1-\sigma)$，最大值只有 0.25，且 $|z|$ 稍大就趋近 0（饱和）。回忆第6课的反向传播——梯度是各层导数连乘，每层乘一个 ≤0.25 的数，10 层之后就是 $10^{-6}$ 量级：梯度消失，底层根本学不动。这是 2012 年前深度网络训练不起来的主因之一。

ReLU：正区间导数恒为 1，连乘不衰减，一举解决梯度消失，且计算只是一次比较。代价是死亡 ReLU——某个神经元如果被推到永远输出负值，梯度恒为 0，从此再也醒不过来。

GELU：$\text{GELU}(x) = x\cdot\Phi(x)$，$\Phi$ 是标准正态的累积分布函数。可以理解成"软 ReLU"：不是硬性地按 $x>0$ 开关，而是按 $x$ 的大小给一个 0~1 之间的通过概率。它处处可导、在 0 附近平滑、负半轴保留一小段非零值（避免死亡）。BERT、GPT-2 用的就是它。

SiLU / Swish：$\text{SiLU}(x) = x\cdot\sigma(x)$。形状和 GELU 几乎重合，但只用一个 sigmoid，更便宜。

4. FFN 的形状与参数账

Transformer 的 FFN 是"先升维再降维"：$d \to d_{ff} \to d$，惯例 $d_{ff}=4d$。参数量：

$$W_1: d\times 4d,\quad W_2: 4d\times d \;\Rightarrow\; 8d^2$$

而注意力只有 $W_q,W_k,W_v,W_o$ 四个 $d\times d$，共 $4d^2$。FFN 占了每个 block 参数量的 2/3。 这个账直接连着第16课的训练显存、第13课的 roofline，也解释了第25课 MoE 为什么专挑 FFN 下手做稀疏化——那里才是参数的大头。

一个常见的解读：注意力负责 token 之间"搬运信息"，FFN 负责每个位置上"查表加工"——很多机制可解释性工作把 FFN 的两层看作 key-value 记忆：$W_1$ 的每一行是一个模式检测器，$W_2$ 的每一列是被写回残差流（第4课）的内容。

5. 门控：从加法到乘法

GLU（Gated Linear Unit）的想法是：不要只对一路信号做非线性，而是开两路，一路当内容，一路当阀门，逐元素相乘：

$$\text{SwiGLU}(x) = \big(\text{SiLU}(xW_{gate})\big) \odot (xW_{up})$$

$$\text{FFN}_{\text{SwiGLU}}(x) = \Big[\text{SiLU}(xW_{gate}) \odot (xW_{up})\Big]W_{down}$$

关键是那个 $\odot$（逐元素乘）。普通 MLP 里所有交互都是加法（加权求和），乘法交互给了网络一种"依输入动态缩放"的能力：门控路可以根据当前 token 决定放行或掐掉内容路的某个通道，等于一个软开关。这个套路你其实已经见过——第28课的 FiLM/adaLN 用条件向量去缩放归一化后的激活，是同一族思想；注意力本身也是一种由数据决定的动态加权。

代价是从 2 个矩阵变成 3 个。为了公平比较（同参数量、同 FLOPs），必须把隐藏维压下来：

$$3 \cdot d \cdot d_{ff} = 8d^2 \;\Rightarrow\; d_{ff} = \tfrac{8}{3}d \approx 2.67d$$

Llama-7B：$d=4096$，$\tfrac{8}{3}\times 4096 = 10922.7$，向上对齐到 256 的倍数 → 11008。那个怪数字的来历就是这里：一半是数学，一半是为了让矩阵乘的尺寸对硬件友好（第14课的 tiling 与合并访存）。

回到案例

Shazeer 2020 做的实验非常朴素：固定 T5 的架构与训练预算，只把 FFN 从 ReLU 版换成各种 GLU 变体（GEGLU、SwiGLU、ReGLU……），按上面的 $\tfrac{8}{3}d$ 规则保持参数量不变，然后比预训练困惑度和下游微调分数。结论是 GEGLU/SwiGLU 稳定地小幅领先——不是碾压，但在同等成本下白拿的收益。论文结尾有一句被引用到烂的自嘲：作者说他们对这些架构为何有效"不提供解释"，把成功归于"神的恩赐"和"炼丹的运气"。

这恰恰是值得你记住的一课：大模型架构里很多默认配置的依据是大规模对照实验，而不是理论推导。 回到第21课的评测视角——这类结论的可信度完全取决于对照是否公平（同参数、同算力、同数据、同超参），而不是理论有多漂亮。

infra 视角还有两点：一是 $W_{gate}$ 和 $W_{up}$ 输入相同、形状相同，实现上通常拼成一个 $d\times 2d_{ff}$ 的大矩阵一次算完，再劈成两半——减少一次 kernel 启动，提高算术强度；二是第25课 MoE 里的每个"专家"，本体就是这样一个 SwiGLU FFN。
