第30课：把图像也变成 token —— VQ-VAE、codebook 与统一多模态生成

本课目标

第11课我们让模型「看见」：ViT 把图像切成 patch，projector 把视觉特征接到 LLM 的残差流上——那是理解方向，图像进、文字出。第10/28课讲了生成方向，但走的是 diffusion 那条路：连续空间、多步去噪。

今天补上路线图里最后一块空白：跨模态生成的另一条路线——把图像也压成离散 token，然后用第2课那套「预测下一个 token」的机器直接生成图像。学完你能回答：

- 图像是连续的像素，凭什么能像文字一样有「词表」？
- 为什么 VAE 的连续 latent 不能直接喂给自回归 Transformer，非要量化成整数？
- 量化是 argmin 取最近邻，这一步没有梯度，模型怎么训得起来？
- 为什么现在既有 Chameleon 这种「文图共用一个词表」的统一模型，又有 Janus 这种「理解和生成用两套编码器」的拆分派？

经典案例

今天没有合适的新论文。用一条经典技术链条：VQ-VAE (2017) → VQGAN (2021) → DALL·E 1——它把「图像生成」变成了「语言建模」，也是今天所有统一多模态模型的地基。

背景铺垫

一、为什么必须离散化

回忆第2课：语言模型的输出层是 logits → softmax → 在 V 个候选里选一个。这套机制吃的是有限词表上的分类问题。第23课我们知道文字天生离散，BPE 只是选切分粒度。

图像不是。第28课的 VAE 把 256×256 图压成 32×32×4 的连续 latent——但 Transformer 拿它没法做 softmax：连续向量的「可能取值」是无穷的，你没法在无穷多个候选上算交叉熵。

所以想复用语言模型这台机器，就得先给图像造一本词典。这就是 VQ（Vector Quantization，向量量化）。

二、codebook：给视觉特征做「最近邻查表」

VQ-VAE 的结构是 encoder → 量化 → decoder：

1. encoder 把图像下采样 f 倍，得到 h×w 个 d 维连续向量 z_e（每个向量对应原图一小块）；
2. 维护一本可学习的码本 codebook E = {e_1, ..., e_K}，K 个 d 维向量——这就是「视觉词表」，K 通常 1024~16384；
3. 量化：每个 z_e 找码本里最近的那一条，把自己替换成它。

$$k = \arg\min_j \|z_e - e_j\|_2, \quad z_q = e_k$$

这一步就是第3课的最近邻检索（注意 ||a-b||² = ||a||² + ||b||² - 2a·b，归一化后等价于点积最大）。关键在于：输出的 k 是个整数——图像就此变成了一串 token id。

压缩账：256×256 RGB 图 = 196608 个数字。取 f=16，变成 16×16 = 256 个 token；K=8192 时每 token 13 bit，总共约 416 字节。第26课的 L² 账在这里立刻生效：token 数决定注意力开销，f 从 16 降到 8 会让 token 数×4、注意力代价×16。这就是「压缩因子」在多模态里的分量。

三、argmin 没有梯度：straight-through estimator

argmin 是阶跃的，梯度处处为 0，decoder 的梯度传不回 encoder。VQ-VAE 用了一个漂亮的 hack——直通估计器（STE）：前向照常量化，反向假装量化不存在，把 decoder 输入端的梯度原封不动抄给 encoder。

$$L = \underbrace{\|x - D(z_q)\|^2}_{\text{重构}} + \underbrace{\|\text{sg}[z_e] - e_k\|^2}_{\text{codebook loss：码本向}z_e\text{靠}} + \beta \underbrace{\|z_e - \text{sg}[e_k]\|^2}_{\text{commitment loss：}z_e\text{向码本靠}}$$

sg[·] 是 stop-gradient（.detach()）。两项形式对称，只是各自冻住一边——这是唯一让码本本身被训练的通道，因为码本没有参与任何可微的前向路径。β 通常取 0.25。

四、码本塌缩（codebook collapse）

VQ 最著名的病：训练几步后只有少数几条码被用到，其余永远选不上——选不上就没梯度，没梯度就永远选不上，死锁。这和第25课 MoE 的路由塌缩是同一个病理（离散选择 + 赢者通吃），只是那边靠 aux loss / 路由偏置治，这边的常用药是：

- 用 EMA（指数移动平均）更新码本，而不是靠 codebook loss 的梯度；
- 死码重启：把长期未命中的码重置到当前 batch 的某个 z_e 上；
- 低维码本 + L2 归一化（把 d 从 256 降到 8~32），让最近邻在低维球面上更均匀——这是后来 ViT-VQGAN 的关键发现。

监控指标记住两个：码本利用率（被用到的码占比）和困惑度（第2课那个 perplexity，这里衡量 token 分布多样性）。

五、VQGAN：为什么 MSE 不够

VQ-VAE 的重构用 L2 损失，结果和第28课提到的 VAE 一样——发糊。原因是 L2 在多个合理解之间取平均，高频纹理直接被抹平。VQGAN 的改法是把重构损失换成：

LPIPS 感知损失（比较预训练网络的深层特征，而非像素）+ patch 判别器的对抗损失（让局部纹理「像真的」）。

代价换来的收益很实在：f=16 的高压缩率下依然清晰，token 数从 VQ-VAE 时代的几千降到 256~1024——正好落进 Transformer 能吃的长度。tokenizer 的重构保真度是整个生成系统的天花板：AR 模型再强，也只能生成码本能表达的东西。

六、第二阶段：把图像 token 当语言建模

两段式训练是这条路线的标志：

- 阶段一：训 tokenizer（VQGAN），得到「图像 → token 序列 → 图像」的双向转换；
- 阶段二：冻结 tokenizer，在 token 序列上训一个标准自回归 Transformer——因果 mask、teacher forcing、交叉熵损失，和第2/6课一模一样。

推理时按光栅顺序（从左上到右下）逐个采样 token，最后交给 VQGAN decoder 解码成图。第8课的 temperature / top-k / top-p 在这里照样能用；第28课的 CFG 也能用——只是不再作用于 score，而是作用于 logits：logits = logits_uncond + w·(logits_cond - logits_uncond)。

缺点也很直白：256~1024 步串行 decode，每步都是 memory-bound（第13课）。两个改进方向值得记住名字：MaskGIT（并行迭代解码——每轮同时预测所有 mask 位置，只保留置信度最高的一批，8~12 轮出图）和 VAR（把「下一个 token」换成「下一个尺度」，从粗到细预测整张 token 图）。

回到案例

DALL·E 1 就是这套拼装的完整体：先训一个离散 VAE（K=8192，把 256×256 压成 32×32=1024 个 token；它用 Gumbel-Softmax 松弛替代硬最近邻，思路等价），然后把 256 个文本 BPE token + 1024 个图像 token 拼成一条序列，喂给一个 12B 的自回归 Transformer 做纯粹的下一 token 预测。文生图于是变成了「给定文本前缀，续写图像后缀」——第9课的条件生成、第5课的位置编码、第16课的显存账，全都不用改。最后再用 CLIP（第3课）给采样出的多张候选重排序，这正是第22课 best-of-N 的雏形。

Chameleon 把这个思路推到底：文本和图像 token 塞进同一个词表、同一个 Transformer（early fusion），实现任意图文交错的输入输出。它踩的坑恰好是第29课的内容——混合模态导致训练极不稳定，必须靠 QK-norm 和调整 norm 位置才收得住。

而 Janus 给出了反向答案：理解和生成需要的表征不一样。理解要语义（SigLIP 那种连续特征就够，还更好），生成要像素细节（必须走 VQ 离散码）。硬塞进一个编码器会互相拖累，于是它把两条编码路径拆开、只共享后面的 LLM。这就是今天「统一 vs 拆分」之争的核心。
